# The experiments of Methodisch inkorrekt!

A catalog of the 243 experiments of the podcast [Methodisch inkorrekt!](http://www.minkorrekt.de),
with one page for each experiment. Each page holds the episode, a title, and a
summary in four points: what one does, what one needs, what happens, and why.
Start at [the overview](index.md).

Ein Katalog der Experimente des Podcasts, mit einer Seite für jedes Experiment.

## Our own words

The titles and the summaries are our own words, written with the help of a
language model from the episodes. They hold no transcript text and no audio of
the podcast. The time in brackets after a point shows where the episode talks
about it. An HTML comment after each point names the exact time mark and the
paragraph of our private transcript that the point comes from.

## Not yet in the catalog

## How it is made

The command `pac publish experiments` of the tool podcast-autocutter makes each
file of this repository. Do not edit the files by hand: the next run overwrites
them. GitHub Pages builds the site from the same Markdown files.
